# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues or pull requests:

- Use GitHub's **Report a vulnerability** button on the Security tab of this repository
  (private vulnerability reporting), or
- email **contact@proxygrid.net**.

Include the affected version or commit, the platform, steps to reproduce and the impact you
expect. We aim to acknowledge reports within 3 business days and to keep you informed until the
issue is fixed. Please give us reasonable time to release a fix before any public disclosure.

## Scope

This repository covers the ProxyGridVPN client apps (the code here). The ProxyGrid hosted service
(website, accounts, API and VPN servers) is operated privately; issues with it can be reported
through the same channels.

Never include real access keys, passwords or other credentials in a report.
