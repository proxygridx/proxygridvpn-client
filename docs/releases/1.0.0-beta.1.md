# ProxyGridVPN 1.0.0-beta.1 (Windows)

First public pre-release of the ProxyGridVPN Windows client, a fork of the
[Outline client](https://github.com/OutlineFoundation/outline-apps).

**This is a beta.** The installers are **not code-signed**, so Windows SmartScreen warns
("Windows protected your PC": click **More info**, then **Run anyway**). Code signing through
the SignPath Foundation program is planned; see [CODE_SIGNING_POLICY.md](../../CODE_SIGNING_POLICY.md).

## Downloads

| Your PC | File |
|---|---|
| Intel or AMD (64-bit or 32-bit Windows 10/11) | `ProxyGridVPN-1.0.0-beta.1-ia32.exe` |
| Windows on ARM | `ProxyGridVPN-1.0.0-beta.1-arm64.exe` |

Check the SHA-256 against `SHA256SUMS.txt` and the build provenance attestation:
[docs/windows.md#verify-a-download](../windows.md#verify-a-download).

## What it does

- **ProxyGrid account mode:** sign in, pick a region and connect, without copying access keys.
- **Own server mode:** use any Outline/Shadowsocks access key, with no ProxyGrid account.
- The installer adds the TAP-Windows6 network driver, one network adapter (`proxygrid-tap0`)
  and the `ProxyGridVPNService` routing service. Its first page explains this. Uninstalling
  removes all three.
- DNS outside the tunnel is blocked while connected.
- Automatic update checks can be turned off under About. No update feed is published yet.

What the app sends and stores: [PRIVACY.md](../../PRIVACY.md).

## Changes from Outline

- Rebranded, with its own adapter, service and subnet, so it can be installed next to Outline.
- `devcon.exe` (Microsoft, proprietary) is replaced by OpenVPN's `tapctl.exe`, built from source
  (GPL-2.0, licence shipped).
- Fixed: when tun2socks ran with administrator rights, the first connect after install could
  leave the adapter without a DNS server, so websites didn't load although the tunnel was up.
- Version information on `tun2socks.exe`, `backend.dll` and `smartdnsblock.exe`.
- Full list of the binaries and their licences: [docs/windows-binaries.md](../windows-binaries.md).

## Tested

- **CI, every build** (clean Windows Server 2022 runner): silent install; driver, adapter and
  service checks; a VPN session test against a local test Shadowsocks server (HTTPS and DNS
  through the tunnel on the first connect after install and on a reconnect, DNS-leak block,
  disconnect); version information; uninstall removes the service, adapter and app.
- **Maintainer, on a Windows PC:** an earlier unsigned test build (`5f1f9c78`) was installed
  and tested with a real ProxyGrid account, and reported OK. This release adds version
  information and documentation changes on top of that build.

## Known limitations

- Unsigned (see above).
- Automatic updates find nothing until an update feed is published.
- The service's control pipe accepts route changes from any signed-in local user (inherited
  from Outline).
- Windows 10 and 11 only. Other platforms are not part of this release.
