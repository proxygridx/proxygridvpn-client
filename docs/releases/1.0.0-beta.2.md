## ProxyGridVPN 1.0.0-beta.2 for Windows

This beta adds the public configuration for ProxyGrid account sign-in that was
missing from beta 1. In account mode, sign in to view plan usage and connect to
an available region. In **My own servers**, use an Outline-compatible access key
without a ProxyGrid account.

| Your Windows 10/11 PC | Installer |
|---|---|
| Intel or AMD (including 64-bit PCs) | `ProxyGridVPN-1.0.0-beta.2-ia32.exe` |
| Windows on ARM | `ProxyGridVPN-1.0.0-beta.2-arm64.exe` |

Installation requires administrator rights and adds a TAP driver, the
`proxygrid-tap0` adapter and the `ProxyGridVPNService` routing service. Uninstall
removes the app, adapter and service; the shared TAP driver package remains.

Publishing this GitHub prerelease does not update existing installations. There
is no update feed in this release.
