## ProxyGridVPN 1.0.0-beta.2 for Windows

**Unsigned beta.** Windows SmartScreen warns ("Windows protected your PC": click **More info**,
then **Run anyway**). Verify the download first (link below).

| Your Windows 10/11 PC | Installer |
|---|---|
| Intel or AMD (including 64-bit PCs) | `ProxyGridVPN-1.0.0-beta.2-ia32.exe` |
| Windows on ARM | `ProxyGridVPN-1.0.0-beta.2-arm64.exe` |

### What's new since beta 1

- **ProxyGrid account sign-in works.** Beta 1 was built without the sign-in configuration. Sign
  in to see your plan and usage and connect to a region. The app uses its own ProxyGrid sign-in
  client.
- **Clearer connection errors.** If sign-in can't reach ProxyGrid, the message now says why (DNS,
  offline, date and time, HTTPS inspection, proxy, firewall or timeout).
- **ProxyGrid Browser:** the tray menu has **Open ProxyGrid Browser**, and ProxyGrid Browser can
  sign in with this app's account after you click **Allow** in a confirmation dialog. Your
  password is never shared.
- **Security updates** for the app's dependencies, and Go 1.26.
- **Tested on Windows on ARM** as well as Intel/AMD in CI.

**My own servers** still works with any Outline-compatible access key, without a ProxyGrid
account.

### Install and uninstall

Installation requires administrator rights and adds a TAP driver, the `proxygrid-tap0` adapter
and the `ProxyGridVPNService` routing service. Uninstall removes the app, adapter and service;
the shared TAP driver package remains.

### Tested

On every build, on clean Windows Server 2022 (Intel/AMD) and Windows 11 ARM runners: install,
VPN connection through a local test server (HTTPS and DNS through the tunnel, DNS-leak block,
disconnect, reconnect), ProxyGrid sign-in reachability from the installed app, version
information, uninstall. A live sign-in and connection with a ProxyGrid account on a desktop PC
is not part of CI.

Publishing this GitHub prerelease does not update existing installations. There is no update
feed in this release.
