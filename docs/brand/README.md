# Brand assets

Logos for ProxyGrid (the platform), ProxyGridVPN (the app) and ProxyGridX (the open-source
organization). They share one grid motif: emerald `#0E9F6E` for ProxyGrid, indigo `#5B5BD6` for
ProxyGridVPN and slate `#111827` for ProxyGridX.

| File | Use |
|---|---|
| `*-mark.svg` | Square marks (app icon, social, favicon source) |
| `*-logo-light.svg` / `*-logo-dark.svg` | Mark with wordmark, for light and dark backgrounds |
| `proxygrid-avatar.svg`, `proxygrid-avatar-500.png` | GitHub organization avatar |
| `proxygridvpn-icon-512.png` | App icon preview |
| `proxygrid-favicon-32.png` | Favicon |
